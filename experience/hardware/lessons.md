## LuzCrawl 使用

- 2026-10-28 两个 LuzCrawl 进程同时跑会互相关闭浏览器（`Target page, context or browser has been closed` / `Multiple Browser Bridge profiles are connected`）。→ 命令一律串行；需要并发只用 `batch --concurrency`。
- 2026-10-28 不带 `--profile` 时用静默 Edge 配置，1688 第二次搜索就要求验证且用户看不到页面。→ 始终带用户 Edge 配置（`doctor` 里 `daemon.profiles[].contextId`）。
- 2026-10-28 1688 在真实配置下约每 2–8 次搜索弹一次滑块；查询间隔 15 秒可明显降低频率。任务被停放后验证页可能已关闭，用户找不到。→ 返回 `awaiting_user` 立即停下请用户处理；用户找不到页面就放弃该批，改走官网、淘宝/京东摘要、厂家渠道。
- 2026-10-28 `while read … done < 文件` 循环里调用 node 时，若用 `&` 挂后台，循环会提前结束。→ 批量脚本用工具的后台运行方式，不在命令里加 `&`。
- 2026-10-28 `search web`（必应）带 `--read 2` 的单条查询要 2–5 分钟；结果页摘要本身常含价格与型号，`--read 1` 足够。
- 2026-10-28 `search <厂商域名> "关键词"` 在海康、大华官网失败（无结果 / Navigation rejected）。→ 直接 `capture` 已知页面（首页、where-to-buy、联系我们、产品页）。
- 2026-10-28 海康官网首页 `capture` 失败，但 `https://www.hikvision.com/cn/where-to-buy/` 可读。

## 价格与渠道

- 2026-10-28 1688 卡片价常是最低 SKU、配件或定金（人脸机搜索出现 18.9 元防雨罩、39 元考勤机）。→ 只采信标题明确是目标型号的卡片，3 个以上样本取中位，剔除离群值。
- 2026-10-28 同一 1688 链接常把多个型号放在一起（如 微耕 L01/L02/L04、海康 671BM/671BMF/671TM），卡片价是最便宜那款。→ 记录 note 说明，正式采购前在详情页选 SKU 核价。
- 2026-10-28 行业方案设备（动火离人热成像、3D 客流、无人门店整套门禁电控）在 1688 基本搜不到真货，只能厂家直采或找方案商。→ 直接查厂商官网"联系我们"和官方公众号文末联系方式。
- 2026-10-28 页面上的电话不一定属于厂商：CSDN 文章页脚的 400 电话是 CSDN 自己的。→ 联系方式必须在厂商官网或厂商官方公众号正文/文末确认，并记录来源页。
- 2026-10-28 必应搜"<型号> 价格"的结果摘要常直接汇总淘宝/京东价格（如 iDS-2CD6810F/C 约 2860 元）。→ 可作零售上限参考，但要拿到原商品链接才能写进清单单价；拿不到就走厂家渠道询价。
- 2026-10-28 涂鸦 TuyaExpo 选品平台首页直接标价（Zigbee 人体存在传感器 ¥299 等），可作为涂鸦生态设备的价格出处。
- 2026-10-28 中国政府采购网按标题检索默认只查近一周；"明厨亮灶"有中标公告（含金额与主要标的），"客流统计"近一周为 0。

## 搜索词

- 2026-10-28 1688 噪声：`POE`（塑料颗粒）、`鱼眼`（钓鱼配件）、`TVT`/`有人物联 DTU`（化妆品）、`客流统计 摄像头`（车载/家用）、型号精确搜索（平板、面具）、`套装`（电子元件）。→ 用"品牌 + 品类中文名 + 型号前缀"，查 `hw_experience.py queries` 看替代写法。

## 选型判断

- 2026-10-28 海康 DS-K1T671M 内置二维码识别，可直接扫小程序动态码，不需另配读头；而韦根读头只能传数字，不能用于服务端验签的动态码。
- 2026-10-28 AB 门防尾随是无人健身房的主流做法（超级艾玛、宇淼、三体云动均提供）：双门互锁 + 缓冲区单人检测；单入口小店可只装单门 + 客流相机告警。
- 2026-10-28 超级艾玛给出的数量公式可直接用：门禁数 = 会员可用入口数；AB 门数 = 需防尾随的通道数；电控回路数 = 需独立控制的区域数（灯光/空调/器械/有氧/淋浴/热水器/招牌）。
- 2026-10-28 动火离人主流两条路：AI 视觉（海康 DS-2XA8T45F/YW-ISP、戈子科技，摄像机内置声光）与热成像双光谱（华感，不受蒸汽灯光干扰）；传统方案是微波/红外人体探测器 + 控制箱 + 燃气切断阀。
- 2026-10-28 明厨亮灶摄像机选型注意 SKU：DS-2XA8T45E/YW-IS 为低性能算法款不带动火离人，DS-2XA8T45F/YW-ISP 才带。

## 实物图

- 2026-10-28 设备实物图用 `scripts/hw_fetch_images.py`：LuzCrawl 打开 360 图片 / 必应图片（两者站点预算独立，轮换使用），取原图或 400px 缩略图下载候选，人工看拼图后 `pick`，必要时 `--crop` 只留设备本体。约 5 分钟一个产品。
- 2026-10-28 直接 HTTP 请求必应图片页只在第一次有效，之后返回固定图库图或空结果；LuzCrawl 预算按注册域名计算（cn.bing.com 与 www.bing.com 共用），换主机名无效；单站预算代码上限 100 次/10 分钟。
- 2026-10-28 电商图多为海报：带大字标题、促销价、多型号拼图。挑正面实物、裁掉文字区；注意子型号（671MF 带指纹 ≠ 671M）。拿不到原厂图时可用同类产品图，并在 catalog 的 notes 写明。
- 2026-10-28 图片存入 `experience/hardware/images/<产品id>.jpg`（480×480 白底），之后任何方案引用同一产品 id 直接复用，不再搜图。
