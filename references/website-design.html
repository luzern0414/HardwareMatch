网站设计规范

适用范围

适用于品牌官网、门店网站、落地页、产品介绍站和内容站，以及交付网页中的网站原型。通用标准见界面通用规范；本页按同样的七层只写网站的细则，没有写到的按通用规范执行。

工作流程

  1. 写出网站的访客、来源（搜索、广告、社交、线下二维码）和每页的主行动。
  2. 画站点地图：页面类型、层级、导航与页脚；每个页面能独立成立。
  3. 按区块写内容：首屏价值、核心服务、证据、流程、价格、常见问题、联系方式；内容来自后台内容管理。
  4. 按断点出图，再做可交互原型；写页面标题与描述。
  5. 用浏览器在 390、768、1280、1920 宽度验证：无横向滚动、导航可用、表单可提交、首屏看得懂。

核心规则

一、设计架构

设计理念

  • 五秒看懂：首屏用一句话说清“你是谁、提供什么、对访客有什么用”，再给一个主行动（尼尔森诺曼集团首页指南：先说明网站的目的）。
  • 一页一个转化目标：每页只有一个主行动（咨询、预约、购买、下载、注册），其余是次行动。
  • 每扇窗都是门：访客常从搜索直接进入内页，每个页面都能独立说明自己并回到首页和主行动。
  • 内容先于装饰：真实照片、具体数字和证据替代空泛口号；扁平、留白充足、可扫读。
  • 快、可搜索、可访问：页面加载快，标题与描述可被搜索引擎理解，键盘与读屏可用。

页面类型

类型主任务构成（自上而下）
首页建立认知并分流导航 → 首屏（价值一句话 + 主行动 + 真实图）→ 核心服务 → 证据（数字、案例、评价）→ 流程 → 联系方式与地址 → 页脚
落地页单一转化首屏（含唯一主行动）→ 痛点与利益 → 证据 → 价格或方案 → 常见问题；滚动后主行动由吸顶栏承接，不放其他分流
产品或服务页了解并比较概述 → 特性 → 场景 → 规格或价格 → 常见问题 → 行动
价格页选择方案方案卡 2–4 张并排，推荐项标记，差异逐项对比
案例与内容列表找到相关内容筛选或分类 → 卡片列表 → 分页
内容详情阅读标题 → 摘要 → 正文（最宽 720）→ 相关内容 → 行动
关于与联系建立信任、联系介绍、团队或门店、地址地图、联系方式与表单
法务页合规隐私政策、用户协议、备案信息

二、功能架构

转化与内容

  • 写出每页的主行动与次行动。主行动放在首屏；首屏滚出视区后，主行动按钮出现在吸顶导航右侧，替换而不是增加，同一时刻页面上只出现一个主行动入口（界面通用规范“一个入口，不重复表达”）。
  • 表单只问必要字段（3–5 个），提交后显示结果与下一步，并说明多久回复；线索去向写进后台。
  • 页面内容（首屏文案、服务、案例、价格、常见问题、门店）由后台内容管理维护，不写死在页面里。
  • 每页写出页面标题（不超过 30 个汉字，含品牌名）与页面描述（约 80 个汉字），标题层级与内容一致（谷歌搜索中心入门指南）；图片写替代文本。
  • 记录关键事件：主行动点击、表单提交、电话与地图点击。

三、信息架构与导航

顶部导航与页脚

  • 顶部导航 5–7 项，用访客的词而不是公司内部部门名；当前页高亮；滚动时吸顶，高 64；首屏离开视区后右侧显示主行动按钮。
  • 桌面端导航直接展开，不收进菜单按钮（尼尔森诺曼集团菜单设计清单）；手机端收进右上角菜单按钮，打开后全屏列出。
  • 下拉菜单与大菜单打开时不遮住整屏，悬停与点击都能打开，键盘可操作。
  • 三层以上的页面显示面包屑；内容站提供站内搜索。
  • 页面主标题写本页内容或结论，不复述导航已高亮的栏目名（规则见界面通用规范“标题不重复导航”）；文章、案例列表默认按发布时间倒序。
  • 页脚：联系方式、地址、主要页面链接、隐私政策、用户协议、备案信息、社交账号；页脚是全站导航的补充，不堆杂项。

  • 区块纵向间距：桌面 64–96，手机 40–56；区块之间可用白与极浅灰交替分隔，不用渐变或斜切。
  • 阅读正文最宽 720，约每行 36–40 个汉字；段落短，小标题多，重要信息放在段首（尼尔森诺曼集团字母形阅读研究：访客先扫左上与段首）。
  • 首屏高度不强制占满屏幕，下一块内容露出一部分，提示可继续滚动。

五、组件

区块组件

组件标准
首屏标题 + 一句价值说明 + 主行动 + 次行动 + 真实照片或产品图；不用自动轮播
特性区块3–4 列，每项线性图标 24–32 + 标题 18 + 两行说明
证据区具体数字（门店数、服务人数）、案例卡、带姓名与身份的评价；不编造
价格表2–4 张方案卡等高并排，推荐项描边与标签，主行动在卡底对齐
常见问题折叠列表，问题 16 像素 600，一次可展开多项
表单单列，输入框高 44，标签在上，提交按钮高 44 通栏（手机）
  • 按钮高 40，首屏主行动 48；链接文字用主色，悬停加下划线。
  • 图片同组同比例，懒加载并预留尺寸，避免布局跳动。

六、视觉基础

视觉

  • 与同品牌其他端共用主题色、字体族与线性图标；扁平风格，页面白底，区块交替极浅灰。
  • 主色只用于主行动、链接与关键数字；营销辅色只在活动区块出现。
  • 首次进入视区的区块可轻微上移淡入（不超过 300 毫秒、只播一次）；不用视差滚动、自动轮播和跟随鼠标的装饰。
  • 性能是视觉的一部分：最大内容绘制 2.5 秒以内、交互响应 200 毫秒以内、布局偏移 0.1 以内（网页核心体验指标）；图片按显示尺寸压缩。

七、文案

文案

  • 首屏标题写访客得到的好处，不写“欢迎来到”与空洞口号；副标题补充对象与方式。
  • 行动按钮写结果：“预约体验课”“获取报价”，不写“提交”“了解更多”。
  • 用访客的词：服务名、价格、地址写具体；数字带单位与时间范围。
  • 页面标题与描述写给搜索结果里的人看：说明这页是什么、为什么点。

案例样本

健身房官网首页的改正

错误

  • 首屏自动轮播三张横幅，标题“欢迎来到动力空间”，按钮“了解更多”。
  • 导航 10 项，用“企业文化”“新闻中心”等内部栏目名；手机端导航挤成两行。
  • 服务介绍写成长段落，没有价格与门店地址。

正确

  • 首屏一张真实门店照片，标题“下班顺路练，24 小时自助健身”，主行动“预约免费体验”。
  • 导航 6 项：课程、会员卡、门店、价格、关于、联系我们；手机端收进菜单按钮。
  • 特性区块 4 项配线性图标，价格表 3 张方案卡，页尾门店地图与联系方式；滚动后“预约免费体验”由吸顶栏承接。

输出契约

位置职责通过条件
站点地图页面类型、层级、导航、页脚每页一个主行动，层级不超过 3 级
网站原型可点击的首页与关键内页各断点无横向滚动，导航与表单可用
页面标题与描述表每页标题、描述、主行动标题含品牌与页面主题，描述说明价值

质量门禁

  • 首屏看不出“是谁、提供什么、下一步做什么”，或一页有多个同等强调的主行动：退回设计。
  • 桌面端导航收进菜单按钮、当前页不高亮、手机端导航挤压换行：退回修改。
  • 自动轮播、视差滚动、装饰渐变、立体图标、正文超过 720 宽或字号小于 14：退回修改。
  • 页面内容写死、表单字段超过必要数量或提交后没有结果：退回设计。
  • 任一断点出现横向滚动、布局跳动明显、图片缺少替代文本、页面缺少标题与描述：退回修改。
