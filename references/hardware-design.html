硬件设计规范

适用范围

适用于系统设计中的硬件部分：无人健身房、无人超市、自助包间、人流与客流监控、动火离人、明厨亮灶等需要现场设备的系统。只要硬件的项目单独建会话；软件与硬件都要的项目在同一个会话里完成，硬件方案与系统架构互相引用。

工作流程

  1. 记录需求：规模、运营模式、已有设备或指定品牌、预算、后台自研或第三方、现场已有什么；缺少会改变选型的关键信息时先问。
  2. 查硬件经验库，读对应场景的业务逻辑。
  3. 写系统方案故事板，再按“设备与连接”选型。
  4. 用真实浏览器调研型号、价格与渠道，补齐经验库没有的部分。
  5. 写方案数据，校验零错误后生成硬件选型清单网页，并用视觉技能的文件检查脚本验收；清单交人工批准，与其他阶段一样在批准账本里记录文件哈希，批准后才发布。
  6. 沉淀经验，交付清单；同时有软件设计时，把设备与集成写进系统架构。

核心规则

一、设计架构

硬件设计回答三件事：这个业务怎么运转 → 每个环节由哪台设备承接 → 设备之间、设备与后台怎么连。软件与硬件在同一个系统里设计：系统架构里的外部集成、状态与流程，与硬件方案里的设备、链路、兜底一一对应。

负责（给出型号与价格或渠道）不负责（现场条件，只提需求）
门禁通行、防尾随、客流与在场人数、动火离人、明厨亮灶识别、智能电控（网络继电器、智能空开、红外）、求助与广播、储物、边缘网关与数据传输终端消防系统、强电与配电、综合布线与基础网络、装修施工；由设备反推对现场的需求：以太网供电口数与功率、12 伏电流、220 伏点位、上行带宽、消防联动接点

二、功能架构

  • 先写系统方案故事板：部署配置 → 核心用户完整旅程（购买、授权、到店、进入、使用、求助、离开、最后一人离开后的环境联动）→ 运营与值班（看板、告警、一键开业与停业、喊话、远程开门、纠正数据、取证）→ 异常兜底（断网、停电、火警联动、设备离线、门未关、计数漂移）。
  • 反向检查：每个步骤都有硬件承接或明确是纯线上；每台要买的设备都出现在某一步里。说不出用在哪一步的设备不买，找不到承接硬件的步骤就是选型缺口。
  • 业务判断（资格、扣次、容量、在场、动火离人规则）在后台或边缘网关执行，设备只负责识别与执行；断网时边缘本地兜底，恢复后补传。

三、设备与连接

  1. 环节 → 设备：每台设备能说出它承接哪个环节。
  2. 设备 → 接口：输出与输入匹配（韦根只传数字、动态码要透传码串、锁控继电器容量、报警输出接控制器输入），先查经验库的匹配规则。
  3. 接口 → 协议 → 后台：每台联网设备定接入方式，写明上报什么、下发什么、用什么协议；连接图每条线都有介质与协议，不出现没有协议的“联网”“对接”。
  4. 兜底：断网时本地网关或设备继续开门、提醒、切断；设备离线有心跳告警。
  5. 现场条件：消防、供电、网络画成现场节点，只写需求，脚本自动汇总供电与网口需求。
  6. 价格或渠道：每台采购设备有“单价加出处链接”或“联系方式”至少一项。
  7. 营业状态联动：每台设备写清门店营业与停业时的动作（门禁与闸机只放行员工、储物柜与取餐柜停止新分配、打印机停止接单、点单机与收银屏显示停业画面、广告屏换停业公告、灯光与空调关闭或节能），由后台营业状态统一下发并逐台回报；下发失败告警，但不影响停业生效。

四、调研与经验

  • 先查硬件经验库：库里结论为首选或可用、价格在 180 天内的产品直接用；只调研库里没有或过期的部分；搜索词先看效果记录，无用的不再用。
  • 型号与接口查厂商官网、规格书与行业产品库；价格查批发平台（下限）、京东自营或官方商城（零售上限）、政府采购中标价（真实成交），同型号三个以上样本取中位。
  • 拿不到价格时，记录厂商官网“联系我们”、页脚热线、官方公众号等公开渠道；个人手机号与微信只存本地联系人库，不进仓库。
  • 每次交付前把新产品、价格样本、匹配规则、采购渠道、搜索词效果和流程经验写回经验库；不沉淀不算交付。

五、安全与合规

  • 门锁必须断电开，出门按钮不经网络；人脸识别必须同时提供二维码等替代方式。
  • 更衣室、淋浴间、卫生间内部不装摄像头；摄像与人脸数据的采集告知、存储与删除写进系统设计的隐私与合规部分。
  • 驱动 220 伏大负载必须经接触器，由电工施工，作为现场条件提出。

六、清单版式

模块呈现文字上限
方案总览合计金额、设备台数、业务模块数、询价数四个指标卡结论一句
系统方案按阶段与角色的故事板，每步一行：编号、操作、响应、异常、参与硬件缩略图、功能标签；末尾设备与阶段对照矩阵操作不超过二十字
系统连接图自动布局矢量图：现场 → 边缘 → 云端 → 使用端，线带编号，链路说明放折叠区结论一句
设备清单按业务模块分组，每台设备一张卡片：实物图、名称、型号、用途、价格、规格与接口标签、采购渠道按钮用途不超过十字
现场条件供电、网口、接点指标卡加要点卡每条要点不超过二十字
预算分级金额卡加按模块降序的单色条形图结论一句
附录（折叠）通信时序、链路说明、接入方式、安装点位、风险与合规、容量计算表格

版式底线遵循视觉技能的视觉设计规范与文件设计规范：唯一主标题、单一字体族、浅色、一个主色、无副标题与自我说明。实物图为白底方图，不用海报文字区、场景效果图或错型号；找不到时用模块图标占位并在交付时列出缺图设备。

案例样本

无人健身房

入口用人脸加二维码双通道门禁，门禁控制器经继电器驱动断电开电锁；客流相机统计在馆人数；边缘网关缓存会员名单，断网时继续核验并在恢复后补传；空调、灯光由智能电控按在场人数联动；现场条件汇总为以太网供电口数、12 伏电流与 220 伏点位。完整示例见技能目录的示例方案。

质量门禁

  • 有设备说不出承接哪个环节，或某个环节没有承接设备：退回设计。
  • 连接图有线没有介质或协议、门锁不是断电开、出门按钮经过网络、人脸没有替代方式：退回设计。
  • 型号没有出处、价格没有链接与日期、拿不到价格又没有联系渠道：退回调研。
  • 把消防、强电、布线当成选型内容，或没有汇总对现场的需求：退回设计。
  • 经验库没有更新，或把个人手机号、微信写进会进仓库的文件：不算交付。
  • 清单没有经人工批准、批准后文件又被改动：不能发布（发布脚本拒绝）。

交接规则

设备清单、链路与协议、接入方式、通信时序和现场条件交给开发技能实现设备接入与后台对接；系统架构中的集成项与硬件方案的设备编号保持一致。
