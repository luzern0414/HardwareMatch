# 硬件基础知识库

每个品类按同一结构写：**做什么 → 关键参数 → 接口与供电 → 怎么接入后台 → 选型要点 → 常见坑 → 代表品牌/型号**。选型时逐项对照，不靠印象写参数；型号与价格必须用 LuzCrawl 在厂商官网或 1688 实测核对（见 [research-playbook.md](research-playbook.md)）。

## 选型范围

本 skill 只对**业务系统本身**负责：无人自助（身份核验、门体执行、防尾随、电控联动、储物、求助广播）、人流监控（客流统计、在场人数、区域密度）、动火离人（明火/灶具状态 + 人员在岗检测 + 告警联动）等。以下三类属于**现场条件**，不进采购清单，只在方案里写清对甲方或施工方的需求：

| 现场条件 | 本方案输出什么 | 不做什么 |
|---|---|---|
| 消防（烟感、消防报警主机、破玻、疏散） | 门禁必须断电开、需要接入的消防联动信号 | 不选消防设备，不设计消防系统 |
| 供电（配电、UPS、门禁电源、接触器） | 由系统设备算出 12V 电流、PoE 口数与功率、220V 点位 | 不选配电与 UPS，不做强电设计 |
| 基础网络（宽带、路由、交换机、AP） | 需要的网口数、PoE 预算、上行带宽、VLAN 与出站端口 | 不选路由交换，不做网络设计 |

第 6、7 节保留这些设备的常识，只用于判断"现场条件够不够"，不是选型对象。

目录：
1. 身份识别与门禁：人脸识别一体机、二维码/刷卡读头、门禁控制器、电锁、出门按钮与破玻、闸机
2. 视频与感知：网络摄像机（枪/球/半球）、鱼眼全景、客流统计、NVR 与硬盘
3. 控制与物联：单片机（MCU）、单板机（树莓派）、物联网网关与 DTU、网络继电器 / IO 模块、智能断路器、红外遥控、传感器
4. 声光与求助：IP 广播、一键报警/可视对讲
5. 业务终端：智能储物柜、自助收银、电子价签、RFID、计时水控
6. 网络：路由器、交换机与 PoE、无线 AP、4G/5G 备份
7. 电源：门禁电源、PoE 供电预算、UPS、配电

## 1 身份识别与门禁

### 1.1 人脸识别门禁一体机（人脸机）

- **做什么**：摄像头 + 屏幕 + 识别算法 + 继电器/韦根输出集成在一台设备。本地比对人脸库后输出开门信号；多数型号同时支持刷卡、二维码、密码、测温（疫情款）。
- **关键参数**：屏幕尺寸（5/7/8/10 英寸）；人脸库容量（常见 1 万–5 万张）；识别距离 0.3–2 m；识别速度 <0.2–1 s；活体检测（双目/红外，防照片视频）；宽动态（逆光门口必需）；防护等级 IP65（户外）；工作温度；**是否带二维码扫码模组**（无人场馆刷小程序动态码必需，型号后缀常带 "Q"/"二维码"）。
- **接口与供电**：12V DC（1–2 A）或 PoE（部分型号）；RJ45 网口；继电器输出（NO/COM/NC，直接驱动电锁或给控制器信号）；韦根输出 26/34（作为"读头"接其他控制器）；韦根输入；RS485；门磁输入、出门按钮输入、报警输入输出；部分有 4G/WiFi。
- **接入后台的四种方式**（按优先级）：
  1. **厂商 HTTP 协议主动上报/下发**：设备配置"平台地址"，识别事件以 HTTP POST/WebSocket 推到你的服务器，你的服务器返回是否开门或下发远程开门指令。海康 ISAPI（`/ISAPI/AccessControl/...`）、大华 CGI/HTTP、中控 ADMS/PUSH 协议、宇泛/魔点等"云平台 HTTP 推送"都属此类。适合自研后台。
  2. **厂商云平台开放接口**：设备注册到厂商云（海康云眸、大华云睿、中控 ZKBioCloud 等），你的后台调云平台 OpenAPI 管理人员、远程开门、订阅事件。省去内网穿透，但依赖厂商云与年费。
  3. **SDK/本地服务**：在门店放一台工控机/边缘网关跑厂商 SDK（海康 HCNetSDK、大华 NetSDK），本地对设备，再由网关通过 MQTT/HTTPS 连云端后台。适合多设备、要离线自治的门店。
  4. **韦根读头模式**：人脸机只输出韦根卡号给门禁控制器，由控制器联网。最兼容但信息最少（只有卡号）。
- **选型要点**：无人场馆要求 ①支持二维码 ②支持远程开门/平台下发人员 ③开放 HTTP 协议或云 API（向厂商索取协议文档，"支持二次开发"写在详情页里不算，必须拿到文档）④活体检测 ⑤宽动态 ≥120dB；人脸数据按法规"存在设备本地、不外传"更合规。
- **常见坑**：1688 低价机多为公版安卓机贴牌，协议不开放或只能用自带 App；"支持 SDK"但只有 Windows DLL；无宽动态导致逆光识别失败；人脸库只认本地，云端下发要额外授权。
- **代表型号**：海康威视 DS-K1T671M / DS-K1T673 系列（7 英寸，支持二维码子型号）、DS-K1T341（4.3 英寸，经济款）；大华 ASI7213/ASI72X 系列；中控智慧（熵基）SpeedFace V5L、ProFace X；宇视 OET-213H。

### 1.2 二维码 / 刷卡读头

- **做什么**：只负责"读"——扫描手机二维码或 IC/ID 卡，把内容输出给控制器或直接联网上报。
- **关键参数**：码制（QR、DM）；**能否读手机屏幕码**（屏幕反光与亮度）；读卡类型 125K ID / 13.56M IC（M1、CPU 卡）；输出接口。
- **接口**：韦根 26/34、RS485、RS232、USB、TCP/IP（联网读头）；12V 供电。
- **接入**：韦根/485 型接门禁控制器；TCP/IP 型（"联网扫码门禁一体机"）直接把码内容 HTTP 上报你的服务器，服务器验证后回"开门"，设备驱动继电器——无人场馆最常用的低成本动态码方案。
- **选型要点**：动态码（30 s 刷新、服务端签名）需要读头把**原始码串**上报，不能只输出韦根数字，所以选 485/TCP 型或"透传模式"。
- **代表**：威尔夫（微耕配套）、新大陆 NLS-FM 系列扫码模组、立德、码上开门（联网扫码一体机）。

### 1.3 门禁控制器

- **做什么**：门禁的"大脑"：接读头（韦根/485）、驱动电锁（继电器）、接出门按钮和门磁，联网接受开门指令、上报记录。
- **关键参数**：门数（单门/双门/四门）；读头接口数；继电器数；卡容量与记录容量；通讯方式（TCP/IP、RS485）；是否支持 **"远程开门 + 实时上报 + 自定义服务器地址"**。
- **接入**：TCP/IP 控制器通过 UDP/TCP 私有协议（如微耕 WG 系列提供协议文档与 SDK）或支持"云服务器模式"主动连接你的服务器。
- **选型要点**：人脸机自带继电器时可以不用控制器；有多个门（主门 + 消防门 + 器械区）或需要统一管理多读头时用控制器；确认控制器"断网时仍能按本地白名单开门"。
- **代表**：微耕 WG2051/WG2052（单/双门 TCP）、中控 C3-100/200、海康 DS-K2601（单门）/DS-K2602。

### 1.4 电锁

| 类型 | 原理 | 断电状态 | 适用门 | 要点 |
|---|---|---|---|---|
| 磁力锁（电磁锁） | 通电吸合 | **断电开**（失电开，符合消防） | 玻璃门、木门、铁门，单开/双开 | 拉力 180/280/350/500 kg；280 kg 单门最常用；需 L/Z/U 型支架；带门磁信号输出型（LED）可检测门是否关好 |
| 电插锁 | 锁舌插入 | 断电开（常见）或断电闭 | 无框玻璃门、木门 | 安装需开孔；带延时与门磁反馈 |
| 阴极锁（电锁口） | 锁扣释放 | 可选通电开/断电开 | 有机械锁的木门、防火门 | 保留机械锁，消防通道常用 |
| 电控锁 | 电机/电磁 | 断电闭 | 铁门、单元门 | 楼宇对讲常用 |
| 智能门锁（联网） | 电池+电机 | — | 小门、包间 | WiFi/蓝牙/NB，适合包间；主出入口不推荐（电池与可靠性） |

- **电气**：12V DC，磁力锁 280 kg 约 300–500 mA；**必须由门禁专用电源供电**，开门信号用继电器断开锁供电回路（磁力锁接 NC，电插锁按说明）。
- **消防要求**：主出入口必须"断电开"，并在门内侧设出门按钮和紧急破玻按钮（直接切断锁电源，不经过控制器），火灾报警信号联动断电。

### 1.5 出门按钮、紧急破玻、门磁

- 出门按钮：无源干接点（NO/COM），接控制器或人脸机的 "Exit" 输入；无人场馆选**非接触红外出门按钮**更卫生。
- 紧急破玻按钮（紧急出门开关）：串在锁电源回路上，按下直接断电，属于消防必配。
- 门磁：检测门开合，接控制器 "Sensor" 输入，用于"门未关好""强行开门"告警，也是防尾随判断的数据之一。

### 1.6 闸机（翼闸/摆闸/三辊闸/速通门）

- 用于严格"一人一刷"的通道。无人健身房一般空间不足，多用"人脸机 + 单门磁力锁 + 防尾随摄像头"代替；人流大的店或无人超市入口才用摆闸/翼闸。
- 接口：闸机主板接受干接点或 RS485 开闸信号，红外对射计数，提供"通行完成""尾随报警"信号；读卡/人脸机装在闸机翼板或立柱上。
- 代表：海康 DS-K3B 系列摆闸、DS-K3G 翼闸；1688 有大量国产机芯 + 机箱的组合，选时要求提供通行计数与尾随报警输出。

## 2 视频与感知

### 2.1 网络摄像机（IPC）

- **形态**：枪机（远距离、方向固定）、半球（室内吸顶）、球机（云台）、筒机。
- **关键参数**：分辨率 200/400/800 万；镜头焦距（2.8 mm 视角约 100°，4 mm 约 85°，6 mm 约 55°）；红外/全彩夜视距离；编码 H.265；音频输入（拾音）；智能功能（人形检测、越线、区域入侵）。
- **接口与供电**：RJ45 + PoE（802.3af，≤ 6.5 W 典型）或 12V DC。
- **接入**：
  - 录像：接 NVR，NVR 用 ONVIF/私有协议拉流存储；
  - 后台看实时画面：RTSP 拉流（`rtsp://user:pwd@ip:554/Streaming/Channels/101` 海康格式）→ 流媒体服务器（ZLMediaKit / SRS）转 WebRTC/HLS/FLV 给后台网页；跨网时用厂商云（萤石、乐橙）或 **GB/T 28181** 国标级联到云端流媒体平台；
  - 智能事件：ISAPI/HTTP 报警主机推送或 SDK 订阅。
- **选型要点**：同一门店尽量同品牌摄像机 + NVR，减少兼容问题；需要后台远程看的确认支持 GB28181 或厂商云；**更衣室、淋浴间、卫生间内部禁止安装摄像头**。

### 2.2 鱼眼全景摄像机

- **做什么**：单镜头 180°/360° 俯视全景，吸顶安装，一台覆盖整个中小型训练区，减少摄像头数量和盲区。
- **关键参数**：分辨率（400/600/1200 万，全景需要高像素才能看清细节）；安装高度 2.5–4 m；**矫正模式**（鱼眼原图、全景展开、四分屏 PTZ）——矫正在设备端、NVR 端还是客户端完成；热度图、人数统计（部分型号）。
- **接入**：与普通 IPC 一样走 RTSP/ONVIF/NVR；在网页播放时原始鱼眼画面是圆形，需选择"设备端矫正输出码流"或在前端做矫正。
- **用途**：无人健身房的训练区安防、**在场人数复核**、跌倒/长时间静止等异常的人工复查。
- **代表**：海康 DS-2CD3956（500 万鱼眼）、DS-2CD6365 系列（600 万全景）；大华 IPC-EBW 系列；宇视 IPC868 系列。

### 2.3 客流统计 / 防尾随摄像机

- **做什么**：双目立体视觉垂直俯拍门口，按进、出方向计数，区分大人小孩、过滤推车；识别"一次开门多人进入"。
- **关键参数**：统计准确率（≥95%）；安装高度 2.2–3.5 m；检测宽度；输出方式（HTTP 推送、ISAPI 事件、报警输出干接点）。
- **用途**：无人场馆**防尾随**（刷一次只允许进 1 人，计数 >1 触发语音警告与后台告警），实时在场人数统计（进−出），客流报表。
- **代表**：海康 iDS-2CD6810F/C（双目客流）、iDS-2CD6412FWD 系列；大华 IPC-HDW8341X-3D 系列。

### 2.4 NVR 与硬盘

- **路数**：4/8/16 路；**PoE NVR**（背板直供摄像机，适合小店）；最大接入带宽；硬盘位（1/2/4 盘）。
- **存储计算**：每路 400 万 H.265 约 2–4 Mbps；单路每天 ≈ 码率(Mbps) × 10.8 GB。8 路 × 3 Mbps × 30 天 ≈ 8 × 32.4 × 30 ≈ 7.8 TB → 选 8 TB 监控盘（紫盘/酷鹰）。
- **接入**：NVR 支持 GB28181 或厂商云，后台通过 NVR 统一拉流/回放；NVR 也可做客流、人脸事件的汇聚。
- **代表**：海康 DS-7808N-R2/8P（8 路 PoE）、DS-7816N；大华 DH-NVR2108HS-8P。

## 3 控制与物联

### 3.1 单片机（MCU）

- **是什么**：一颗芯片集成 CPU、RAM、Flash、GPIO、串口、ADC 等，跑裸机或 RTOS 程序，功耗低、启动快、实时性好，但不跑 Linux。
- **常用**：ESP32 / ESP32-S3 / ESP32-C3（乐鑫，带 WiFi + 蓝牙，最适合自研联网小设备，支持 MQTT）；STM32（意法，工业控制，常配 4G 模组或以太网芯片 W5500）；GD32（国产 STM32 兼容）；CH32（沁恒）。
- **用途**：自研继电器控制板、传感器节点、储物柜锁控板、按钮/指示灯控制。
- **接入**：ESP32 直连 WiFi → MQTT Broker；STM32 + 4G Cat.1 模组（移远 EC800、合宙 Air780E）→ MQTT。
- **选型要点**：量少优先买成品模块（网络继电器、DTU），量大或要定制时再做单片机板；做商用必须过电气安全与电磁兼容，**驱动 220V 负载要用继电器 + 隔离，并装在配电箱内**。

### 3.2 单板机（树莓派等）

- **是什么**：一块板上的完整 Linux 电脑（ARM CPU、内存、网口、USB、HDMI、GPIO）。
- **常用**：树莓派 4B / 5（官方）、香橙派 Orange Pi 5（RK3588S，带 NPU 可跑视觉模型）、瑞芯微 RK3568/RK3588 工控盒、NVIDIA Jetson Orin Nano（边缘 AI）。
- **用途**：门店**边缘网关**——跑厂商 SDK 对接人脸机/NVR、本地 MQTT 桥接、断网缓存与本地放行、ONVIF/RTSP 转发、语音播报、本地 AI 识别（跌倒、尾随）。
- **选型要点**：商用门店优先买**工业级 ARM 网关/工控盒**（宽温、金属外壳、DIN 导轨、看门狗、eMMC 而非 SD 卡），树莓派适合原型与小规模；必须有远程运维（SSH 隧道/FRP/ZeroTier/厂商云）与看门狗自恢复。

### 3.3 物联网网关与 DTU

- **DTU（数据传输单元）**：把串口（RS485/RS232）数据透传到网络（4G/以太网/WiFi），支持 MQTT/TCP/HTTP；用来让 485 设备（电表、传感器、继电器）上云。代表：有人物联 USR-G780（4G）、USR-DR302（485 转以太网）；塔石 TAS 系列；合宙。
- **边缘网关**：带协议转换（Modbus → MQTT）、边缘计算、多接口（多路 485、DI/DO、以太网、4G），可跑脚本。代表：有人物联 USR-M300、研华 WISE、鲁邦通。
- **Zigbee/蓝牙网关**：连接无线传感器（门磁、人体、温湿度、烟感），涂鸦/小米/Aqara 生态，云对云接入或本地 MQTT。

### 3.4 网络继电器 / IO 控制模块

- **做什么**：通过网络（以太网/WiFi/4G）远程控制若干路继电器开合，读取 DI（干接点输入）。用来控制灯光接触器、空调电源、新风、广告屏、门锁辅助回路。
- **协议**：Modbus TCP / Modbus RTU（485）、MQTT（直连 Broker，最适合自研云后台）、HTTP。
- **选型要点**：继电器触点容量（10 A/250 VAC），大功率负载（空调、照明总路）必须**由继电器控制交流接触器**，不直接带载；选支持 MQTT 自定义服务器、断网后状态保持、上电状态可配置的型号。
- **代表**：有人物联 USR-IO808/IO424（Modbus/MQTT）、中盛、聚英 JY-DAM 系列、康耐德。

### 3.5 智能断路器（智能空开）

- **做什么**：替代配电箱里的普通空开，可远程分合闸、计量电量电流、过压欠压保护，回路级控制（照明、空调、插座、热水器）。
- **接入**：WiFi/4G/485 + 厂商云或 Modbus/MQTT；与"在场人数为 0 自动关灯关空调"联动。
- **代表**：正泰 NXBLE 智能断路器、德力西、良信、涂鸦方案的 4G/WiFi 智能空开；1688 有大量"4G 物联网智能断路器"。
- **注意**：配电必须由持证电工施工；智能断路器选有 CCC 认证的品牌产品。

### 3.6 红外遥控器（空调）

- WiFi 红外转发器学习空调遥控码，云端/本地控制开关、温度。适合挂壁/柜式家用空调；中央空调用网关（如 485 线控器协议）或智能断路器控制。
- 代表：涂鸦/智能生活 WiFi 万能遥控器、小米万能遥控器、BroadLink 博联 RM4。

### 3.7 传感器

| 传感器 | 用途 | 接口 |
|---|---|---|
| 门磁 | 门开合、强开告警 | 干接点 / Zigbee |
| 人体红外（PIR） | 区域是否有人、夜间入侵 | 干接点 / Zigbee |
| 毫米波人体存在 | 静止人体也能检测（防"长时间不动"漏报） | UART / Zigbee / WiFi |
| 温湿度 | 环境监控、空调联动 | 485 Modbus / Zigbee |
| 烟感 | 火灾报警，联动断锁电 | 独立式 / NB-IoT / 4G 联网烟感 |
| 水浸 | 淋浴区、机房漏水 | 干接点 / Zigbee |
| 电表 | 能耗统计 | 485 Modbus（DL/T645） |

## 4 声光与求助

### 4.1 IP 网络广播

- **做什么**：网络音柱/吸顶音箱，后台 TTS 文本或音频文件推送播放（"欢迎光临""请勿尾随""营业结束请离场"）。
- **接口**：RJ45 + PoE，SIP 或厂商协议；部分支持 HTTP 接口直接推 TTS。
- **代表**：海康 DS-QAZ 系列网络音柱、itc 保伦、ip 广播 SIP 音箱（1688 大量）。最低成本方案：人脸机自带喇叭 + 边缘网关接有源音箱。

### 4.2 一键求助 / 可视对讲

- **做什么**：场内（器械区、淋浴区外、门口）按下即呼叫值班人员；带摄像头的可视对讲可双向通话。
- **接入**：SIP 可视对讲终端（呼叫值班手机 App/SIP 账号）；或报警按钮（干接点）接网络 IO 模块，后台产生告警并推送值班人员（短信/电话/企业微信）。
- **代表**：海康 DS-PEA 一键报警柱/报警箱、SIP 一键求助终端。

## 5 业务终端

- **智能储物柜**：电控锁 + 锁控板（RS485 主板）+ 主控（扫码屏或无屏）。接入：主控 4G/WiFi 连厂商云或你的 MQTT；入场后小程序分配柜门、离场释放。注意锁控板协议（常见 485 协议，每块板控 24/48 门）。
- **自助收银机 / 自助结算台**（无人超市）：扫码枪 + 屏 + 支付盒（微信/支付宝刷脸支付设备，如微信青蛙 Pro、支付宝蜻蜓）。
- **RFID**：超高频（UHF 920 MHz）标签 + 通道读写器，无人超市"拿了就走"结算或防盗；成本按标签计。
- **电子价签（ESL）**：2.4G 或 NFC 基站推价。
- **计时水控**：淋浴扫码/刷卡计时计费，485/4G 联网。
- **智能体测仪**：InBody、乐心等，蓝牙/WiFi 上传数据，属可选增值。

## 6 网络（现场条件，只用于提需求）

- **路由器**：选企业级（多 WAN、VPN、VLAN、行为管理、云管理）：TP-LINK TL-ER3220G / ER6229GPE（自带 PoE）、H3C ER3200G3、锐捷睿易 EG105G-P、华为 AR 系列。**双链路**：宽带 + 4G/5G 备份（4G 路由器或支持 USB/LTE 模块的企业路由器），保证断网时门禁仍能联网核验。
- **交换机**：PoE 交换机给摄像机、人脸机、音柱、AP 供电；看端口数与**总 PoE 功率预算**（如 8 口 PoE，总功率 120 W）。代表：TP-LINK TL-SG1210P、海康 DS-3E0510P、H3C S1208V-HPWR。
- **无线 AP**：会员用 WiFi（营销认证）与设备 WiFi 分开 SSID/VLAN。代表：TP-LINK 吸顶 AP、锐捷睿易。
- **网络规划要点**：设备网与会员网 VLAN 隔离；设备固定 IP 或 DHCP 绑定；设备主动出站连接云（MQTT/HTTPS），**不在路由器上开放端口映射**；远程运维走 VPN/云管理。

## 7 电源（现场条件，只用于提需求）

- **门禁专用电源**：12V 3A/5A，带后备电池接口（12V 7Ah 铅酸）与消防联动输入（接收火灾信号断电），电锁和控制器共用；断电后电池维持控制器与人脸机工作数小时（按负载计算）。
- **PoE 供电预算**：Σ设备功率 ≤ 交换机/NVR 总 PoE 功率 × 0.8；单口 af 15.4 W、at 30 W。
- **UPS**：机柜（路由器、交换机、NVR、网关）配 1–2 kVA 在线式或后备式 UPS，断电维持 ≥ 30 分钟，保证"停电时会员能离场、记录能上传"。
- **配电**：照明、空调、插座、门禁、弱电机柜分回路；弱电机柜独立回路 + UPS。
- **功率估算**：

| 设备 | 典型功耗 |
|---|---|
| 人脸机 7 寸 | 8–12 W |
| 磁力锁 280 kg | 4–6 W |
| 门禁控制器 | 3–5 W |
| 网络摄像机 | 4–7 W |
| 鱼眼/客流双目 | 7–12 W |
| NVR（不含 PoE 输出）+ 硬盘 | 15–25 W |
| 路由器 / 交换机 | 10–20 W |
| 边缘网关 | 5–15 W |
| IP 音柱 | 10–20 W |
