# 其他无人/少人场景速查

拿到一个新系统时，按 [unmanned-gym.md](unmanned-gym.md) 的结构写一份同样的场景文件（运营逻辑 → 会员动线 → 功能-设备映射 → 时序规则 → 本场景检查要点 → 完整系统方案：部署、核心用户旅程、运营值班、异常兜底四段），并先用 LuzCrawl 调研 3 家以上同类 SaaS/硬件厂商方案。下面是常见场景的骨架，作为起点而不是结论。

## 无人超市 / 无人便利店

- **运营逻辑**：24 小时营业；商品自选，自助结算；损耗（偷盗、漏扫）是最大风险；补货与盘点靠后台库存 + 远程巡店。
- **主流技术路线**：
  1. *扫码自助结算*：入口扫码/刷脸门禁 → 顾客自选 → 自助收银机（扫码枪 + 刷脸支付盒）结算 → 出口凭支付凭证开门；成本最低。
  2. *RFID*：每件商品贴 UHF 标签，出口通道读写器自动识别结算或防盗报警；标签成本 0.2–0.5 元/件，适合高客单。
  3. *视觉 + 重力货架*（拿了就走）：大量摄像头 + 称重层板，算法识别取放，成本高。
- **关键设备**：人脸/扫码门禁、出口闸机或门（支付后开）、自助收银机、刷脸支付设备（微信/支付宝）、扫码枪、RFID 通道门/标签、监控（含货架区鱼眼）、电子价签、冷柜温度监控、智能电控、IP 广播、网络与 UPS。
- **规则**：出口"未支付不开门"需同时保证消防"出门不依赖网络"——出口门用电磁锁 + 消防破玻，未支付离开靠视频追溯与黑名单，不能把人锁在店内。

## 自助棋牌室 / 自助台球 / 自助 KTV / 自习室（按时段预约的包间类）

- **运营逻辑**：小程序预约时段并支付 → 到店扫码开大门 → 扫码开包间 → 包间通电（灯、空调、台球桌灯、麻将机）→ 到时提醒续费 → 超时自动断电 → 保洁。
- **关键设备**：大门扫码门禁、包间智能门锁（WiFi/蓝牙/4G）或扫码门禁、**每包间一路网络继电器/智能空开**（按预约通断电）、空调红外遥控、包间外摄像头（包间内一般不装或仅装在公共区）、IP 音箱（到时提醒）、烟感。
- **接入特点**：设备多、单价低，常用"4G/WiFi 智能空开 + 厂商云 API"或"ESP32 继电器 + 自建 MQTT"。

## 自助洗车 / 共享储物 / 自助洗衣

- **核心**：支付 → 设备启动 → 计时/计量 → 结束断电。设备侧为"支付控制盒"（4G + 继电器 + 计时），对接后台用 MQTT 或厂商协议。

## 智慧社区门禁 / 共享办公

- **核心**：人员权限下发到多台门禁（人脸、卡、二维码），访客临时码，梯控；多门禁统一平台管理，常用厂商平台或 SDK 网关。

## 场景到设备类别的通用映射

| 业务需求 | 设备类别 |
|---|---|
| 谁能进 | 人脸机 / 扫码读头 / 刷卡读头 + 门禁控制器 |
| 门怎么开关 | 磁力锁 / 电插锁 / 闸机 / 智能门锁 + 门禁电源 |
| 怎么安全出去 | 出门按钮、破玻、消防联动（本地，不依赖网络） |
| 进了几个人 | 客流统计相机、AB 门、闸机红外计数 |
| 场内发生了什么 | 鱼眼/半球/枪机 + NVR、毫米波/PIR、求助按钮 |
| 怎么提醒/喊话 | IP 广播、屏幕 |
| 用电怎么控制 | 网络继电器、智能断路器、红外遥控、接触器 |
| 怎么付费结算 | 小程序支付、自助收银、刷脸支付、计时控制盒 |
| 怎么连上后台 | 路由器 + 4G 备份、交换机/PoE、边缘网关/DTU、MQTT/HTTPS |
| 停电怎么办 | 门禁电源后备电池、UPS、断电开锁 |
